# 알려진 한계

[← README](../README.md)

- 기어가 D인 동안 Pleos OS가 앱 화면을 가립니다("주행 중에는 사용할 수 없습니다"). 앱 서비스는 화면이 가려져도 계속 기록하고, 질문·정리 카드는 주차한 뒤에만 뜹니다.
- 출발·도착 위치는 등록 장소 이름만 씁니다(내비 현재 위치가 에뮬레이터에서 고정이라 주소 변환은 제외).
- 좌석 위치로 사용자를 추천하는 기능과 주차 브레이크 표시는 에뮬레이터에서 값을 바꿀 수 없어 넣지 않았습니다.
- TTS는 앱을 새로 설치한 뒤 첫 호출만 재생 이벤트가 확인됩니다. 질문은 항상 화면 카드로 뜹니다.
- 운행기록부 칸 구성은 제3자가 올린 서식 사본 기준이라 국세청 원본과 대조가 필요합니다.
- 에뮬레이터의 Virtual Console은 주행거리를 올릴 수만 있고 줄일 수 없습니다. 시연 스크립트는 현재 값에서 시작하도록 만들어 이 제약과 무관하게 실행됩니다.
- 내보낸 파일은 앱 전용 폴더와 `Download/AutoLog/`에 저장되지만, 에뮬레이터에서는 `adb pull`이 권한으로 막힙니다. 꺼내는 방법은 [검증 기록](VERIFICATION.md)을 참고하세요.
- 음성 답변(STT)은 에뮬레이터 마이크가 무음이라 실제 말로는 확인하지 못했습니다(PCM 음성 파일로 부분 결과까지 확인).

각 항목의 측정값과 근거는 [검증 기록](VERIFICATION.md)에 있습니다.
